# Recall

A self-hosted practice app for keeping technical skills sharp through spaced recall.

## Motivation

Personal practice session to remain sharp. 

- Python
  - Datetime
  - Exception Handling
  - PySpark
- Bash Commands
- Data Types
- SQL
- Git
- Container & Docker

## Goals

- **Free-form Q&A**: answer questions in natural language instead of picking from options.
- **Varied phrasing**: use a language model to rephrase questions.
- **Answer evaluation**: have the language model assess my written answers.
- **Interview practice**: optionally act like a technical interviewer, asking follow-up questions.
- **Growing question bank**: build a database of questions and reference answers over time.

## Planned stack

- **Backend**: Python with Flask
- **Database**: MySQL
- **Model**: SLM or LLM
- **Deployment**: Docker container
